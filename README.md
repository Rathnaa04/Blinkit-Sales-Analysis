# Blinkit Sales & Inventory Analysis Dashboard

## Project Overview

The **Blinkit Sales & Inventory Analysis Dashboard** is an interactive Power BI project designed to analyze sales performance, product categories, customer ratings, and outlet-level performance.

The dashboard transforms raw data into meaningful business insights using **Power BI, SQL, and Excel**, helping users understand key performance indicators and identify sales trends across different outlet types, sizes, locations, and product categories.

## Objectives

* Analyze overall sales and outlet performance.
* Identify high-performing product categories.
* Compare sales across different outlet types and sizes.
* Analyze customer ratings and item-level performance.
* Track key business performance indicators through interactive dashboards.
* Generate data-driven insights to support business analysis.

## Tools & Technologies

* **Power BI** – Dashboard development and data visualization
* **SQL** – Data querying and analysis
* **Microsoft Excel** – Data cleaning and preprocessing
* **DAX** – Measures and calculated metrics

## Key KPIs

The dashboard provides insights into the following key metrics:

* **Total Sales**
* **Average Sales**
* **Number of Items**
* **Average Rating**

## Dashboard Analysis

The dashboard provides analysis across:

* Outlet Type
* Outlet Size
* Outlet Location
* Product Categories
* Item Performance
* Sales Trends
* Customer Ratings

Interactive visualizations allow users to filter and explore the data based on different business dimensions.
